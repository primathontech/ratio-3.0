## B — Merchant code + extensibility runtime (REQ-1, REQ-3) — the new KILL cluster

| #    | Class | Risk / unknown                                                                                                                                                                                                                                                                                                                                                                                                                                            | Spike / POC                                                                                                                                                                                        | Rule-out criteria                                                                                                                                                 |
| ---- | ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| B1   | KILL  | **Template language sandbox.** Handlebars = JS helpers, prototype-escape history, no resource limits — hostile merchant template in shared origin = cross-tenant read or DoS. Liquid(JS) designed for hostile input                                                                                                                                                                                                                                       | Spike (2–3d): LiquidJS vs sandboxed Handlebars. Attack suite: prototype escape, 10⁹-iteration loop, 100MB string, recursive include, `constructor` access. Measure render µs/widget + compile cost | No escape + hard CPU/time/size caps enforceable per render + perf ≤ 2× current mock. **Decides D8 — blocks merchant code editing entirely**                       |
| B2 ✎ | KILL  | **Binding-based cacheability inference** — REQ-3 says devs declare nothing, so tier must be COMPUTED: parse template → extract referenced variables → diff vs declared bindings → reject undeclared refs. **Must cover ALL capabilities, not just var refs: time (`now`), randomness, filters with data access, includes/renders of other templates** — any of these smuggled past the parser = purity is fiction                                         | POC: AST-walk (LiquidJS exposes AST) → capability extraction → reject-on-undeclared. Red-team: dynamic property access `{{ x[y] }}`, filter side effects, nested includes, date/random tags        | Zero smuggle paths, or the offending syntax banned outright. **If inference can't be made sound → REQ-3 needs dev declarations after all (product call changes)** |
| B3 ✎ | KILL  | **CSP contradiction + CSP ≠ sandbox.** ratio-3.0 ships `script-src 'none'`; islands need JS. And: nonces/allowlists control what LOADS, not what loaded code can DO — any same-context script can read/mutate the whole page. So: **first-party islands** = CSP `'self'` + SRI (we author them). **Third-party app islands = sandboxed cross-origin iframe + postMessage capability bridge — mandatory**, or the app is explicitly human-reviewed/trusted | Design spike: CSP v2 for first-party; iframe sandbox + bridge prototype for lane-B apps; threat-model both                                                                                         | First-party dispatcher runs under `'self'`; app code demonstrably cannot touch host DOM/cookies outside its slot                                                  |
| B4   | ENG   | Compiled-template memory at scale: 1000 tenants × 20 custom widgets × versions in one shared origin process                                                                                                                                                                                                                                                                                                                                               | Load spike: measure bytes/compiled template, LRU cap + recompile cost                                                                                                                              | Bounded memory (LRU), recompile p99 < 10ms — no OOM path                                                                                                          |
| B5   | ENG   | App kill-switch + metering: one bad app must be disable-able per-tenant AND fleet-wide in seconds, with per-app CPU/error attribution                                                                                                                                                                                                                                                                                                                     | Design + thin POC alongside first app widget                                                                                                                                                       | Kill flag propagates < 60s (KV again); per-app render CPU visible in metrics                                                                                      |

Kill-decision map: **B1/B2 fail → REQ-1/REQ-3 change shape (declared tiers, curated widgets). A3 amplification unacceptable → rendered-body shield / publish batching. C1/C2 fail → personalization narrows to islands-only. D1 fail → cells move up the roadmap.** (A1 closed by design — D27/D28; POC verifies.) Nothing on this list fails silently into production — that's the point of the register.
