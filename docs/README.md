# docs/

Plain-English explainers and flow walkthroughs for how Ratio 3.0 works — the
"how does it all fit together" reading, with diagrams.

This is the narrative layer. It complements, and does not replace:

- **[INFRASTRUCTURE.md](../INFRASTRUCTURE.md)** — the deep architecture + infra + env/secrets source of truth.
- Per-package `README.md`s — how one package works.
- Confluence ADRs — the recorded decisions and their rationale.

Keep each doc to one topic, in simple language, and link out to the source-of-truth
above rather than duplicating it.

## Index

- [page-builder-end-to-end.md](./page-builder-end-to-end.md) — how a page is built and served, from the shopper's click to the HTML, including the data layer, theme, and cache purge.
